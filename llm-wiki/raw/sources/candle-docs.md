# What it says

- Candle is a minimalist ML framework for Rust.
- The docs list CPU, CUDA, WASM, and serverless-on-CPU among the goals, and loading safetensors among the file formats.
- It is an optional runtime. It does not replace PyTorch. Example-model counts are not used. A mention of the safetensors file format is not a claim about the safetensors implementation language.
