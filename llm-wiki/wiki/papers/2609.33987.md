# Opera: A Verbal Critic Framework for Long-horizon Coding Agents

Topic: [agent self-improvement](/wiki/topics/agent-self-improvement.md). Authors: Kai Mei et al. arXiv 2609.33987.

## TL;DR
Opera proposes a verbal critic framework for long-horizon coding agents. Instead of giving one-off feedback, it acts like a sticky note that persists until the issue is fixed, leading to large improvements across standard benchmarks.

## Summary
The paper details how standard critics provide one-time feedback which agents often ignore. Opera addresses this by holding on to the feedback (persistent notes) and verifying if the subsequent actions resolve the identified issue.

## Key Numbers
- 15.0 percentage points absolute gain on a SWE-Bench Pro subset.
- 10.2 percentage points gain on held-out repositories after fine-tuning.
- 3 benchmarks evaluated: Terminal-Bench 2.1, SWE-Bench Pro subset, and DeepSWE v1.1.
