How to read a model release table

Idea sketch. A short reel that teaches anyone to read the benchmark table that comes with a new AI model, using the Muse Wonder table as the worked example. The mascot guides.

New model table→ Who made it, and what do the colours mean?→ Which row matches my work?→ Is the gap real?→ Test it on my own tasks

Mascot: Lens

A small orange robot with one magnifier eye and a mini scorecard on its chest. It reads things closely, which is what the reel teaches. Files are in mascot/ (generated by mascot.mjs).

What is decided and what is open

Decided in the discussion

  • Topic reel, neutral explainer, no "best overall" claim
  • Source asset is the screenshot plus the lab's report
  • Mascot guides, one narrator voice
  • Reusable "how to read any release table"
  • Honest scope: vendor-reported, tasks not jobs

Open

  • Report link and the lab's name, to check every digit read from the image
  • Does the mascot look right (name, colours, poses)?
  • Reel 1 on this table, then a shorter version per release?
  • Is the whole screenshot complete?

How it would be built

  • reel-director: treatment and script
  • cold-viewer: can a newcomer explain it back?
  • reel-producer: HyperFrames scenes, table crops at full resolution, mascot poses animated
  • reel-validator and retention-critic, then your yes

All numbers in the mock frames are read from the screenshot you shared and are not yet checked against the source page.
