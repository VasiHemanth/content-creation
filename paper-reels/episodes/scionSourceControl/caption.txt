Anthropic reports a 200× smaller CPU and memory footprint for its source-control infrastructure versus its old Git mirrors. This is how the cache architecture works.

Scion serves the immutable trees and blobs a job needs through a shared node daemon, regional caches, and authoritative servers. Some source-control API jobs need no local repository.

Git already supports partial clones and sparse tools; Anthropic used those features before this redesign. Scion targets its unusual enormous-monorepo and always-online agent workload. It is not a general Git replacement. Adoption would also require bespoke code review, search, and CI.
