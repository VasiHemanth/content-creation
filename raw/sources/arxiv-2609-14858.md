# What the paper says

- Problem: in long-horizon discovery, exploration policies are mostly fixed; optimizing them online needs long, expensive rollouts, because a policy is judged by how it shapes many proposal-evaluation cycles.[^p1]
- Method: a lightweight orchestration layer makes exploration explicit and programmable (branching, parallel exploration, stopping) and leaves the coding agent unchanged.[^p1]
- A completed discovery run is a tree: each node is one generation-evaluation attempt with its workspace, artifact, diagnostics and score. The paper treats this history as a replay simulator ("replay simulator" and "worlds" are used for the same thing). A new policy is evaluated by revealing recorded outcomes along the branches it selects, "without rerunning the underlying discovery agent or evaluator".[^p2]
- Loop: online exploration with the current policy, then simulator construction, then "dreaming": a fixed LLM-based policy-development agent revises the exploration-policy code over M versions, each scored on all replay worlds; the version with the best average replay score is redeployed online. Only the exploration-policy code changes.[^p4]
- Replay returns recorded children only; no outcomes beyond the recorded tree are generated.[^p6]
- Replay score: best quality reached, minus a cost per attempt, plus a bonus for attempts per decision round (eq. 1).[^p6]
- Evaluation: 8 tasks in algorithm engineering, mathematical optimization and GPU kernel engineering. Controlled baseline: Recursive Fixed Exploration (same agent, evaluator, initialization and budget; the policy stays fixed). Discovery agents: Gemini-3.1 Pro and Gemini-3.7-Flash through the Gemini CLI. Discovery cost is the cumulative number of discovery-agent calls.[^p7]
- Lasso regularization path (sec 4.1): with Gemini-3.1 Pro, average runtime on six held-out datasets 3587.1 ms (fixed) to 2931.0 ms, using 317 discovery-agent calls against 550. With Gemini-3.7-Flash, 2516.7 ms to 2350.6 ms with 1879 calls against 3200. SimpleTES (gpt-oss-120b, 51,200 generations) averages 3804.8 ms.[^p8]
- Mathematics (sec 4.2, Table 1, Gemini-3.1 Pro, 10 rounds): Sum-Difference 1.145427 (fixed 1.144047, SimpleTES 1.143975); Circle Packing 2.635983, equal to the best reported; Autocorrelation 1.456375 against SimpleTES 1.453675 (lower is better), which used 51,200 generations.[^p9]
- GPU kernels (sec 4.3, Figure 4, KernelBench): VGG16 and LayerNorm reach comparable performance with 2.43x and 1.79x fewer generations; ConvDiv and ConvMax reach 2.09x and 1.44x higher performance under comparable budgets.[^p10]
- Analysis (sec 5): turning history into prompt-level guidance underperforms replay on ConvDiv (Figure 5). On ConvDiv the learned policy cut evaluated attempts from 110 to 50 as performance improved, then raised effort when progress plateaued (Figure 6).[^p11]
