# ContextEvo

Topic: [agent context management](/wiki/topics/agent-context-management.md). Also relevant to [agent self-improvement](/wiki/topics/agent-self-improvement.md). Authors: Weiyuan Li, Jinghan Xu and 5 others (Fudan University). arXiv 2609.34649v1, submitted 2026-09-28.

## 1. Identity
"Beyond Skill Evolution: Self-Evolving Context Management Policies for Long-Horizon Agent Harnesses", arXiv 2609.34649, version v1 (the version the video was made from).[^paper]

## 2. What problem does it address?
On long agent tasks, useful evidence gets buried by redundant or outdated context, and harness-evolution methods that add experience or skills do not fix how that context is managed.[^paper]

## 3. What is the method?
The model stays fixed; the harness learns a context policy that decides what the model sees, along three dimensions: what enters the context (Input Assembly), how history is kept (History Maintenance) and how context is shared with sub-agents (Context Orchestration). From held-in trajectories, ContextEvo rebuilds the model-visible context page by page, labels context failures as missing, degraded, buried or polluted evidence (separately from the model's own errors), and, when the trajectories do not settle a case, replays one decision point with an edited context to see whether the next action changes. Only supported attributions become a constrained edit to the policy; otherwise the policy stays the same.[^paper]

## 4. What is the evidence?
All results are the authors' own runs, one run per task, implemented in the Pi-agent harness with DeepSeek-V4-Flash-0731 and GPT-5.6-Luna.[^paper]
- Skill-only comparison on all 46 Long-Horizon-Terminal-Bench (LHTB) tasks (sec 6.1, Table 3): baseline 0.417, skills learned from the same held-in runs 0.370, ContextEvo 0.448, ContextEvo plus skills 0.419. Mean tokens per run: 8.57M, 9.61M, 7.52M and 9.69M. Only 20 of 44 inspectable skill-only runs read a skill body. The model is not named in sec 6.1; the scores match the DeepSeek-V4-Flash rows of Table 2.
- Full-set scores rise over Pi-agent in all six benchmark and model settings after two iterations (Table 2), for example LHTB 41.7 to 45.3 and DeepSWE 64.6 to 71.7 with DeepSeek-V4-Flash.
- Against static and locally evolved context compression (ReSum, ACON, TACO) under GPT-5.6-Luna, ContextEvo scores highest on all three benchmarks (Table 4).
- Ablation on LHTB: removing the paginated review costs the most (44.78% to 32.64%).

## 5. What does it not show?
- Variance: "Each task is attempted once" (App. A.2). No error bars, seeds or intervals anywhere.
- Held-out generalization: full-set scores include the held-in tasks the policy was learned from. Held-out results vary and sometimes fall, for example GPT-5.6-Luna on held-out DeepSWE (18.5, 15.4, 13.8 over base, iter-1, iter-2) and iter-1 on held-out BrowseComp-Plus for both models. The authors say so in sec 7.
- The skill-only result is one benchmark and one model, over all 46 tasks including the 20 held-in ones, with no held-out split in Table 3. It tests one skill-evolution recipe (following Zhang et al., 2026a), not skills in general.
- Cost of the evolution loop itself (reviewer, judge, replay and editor calls): Open question. Table 3 tokens are per evaluation run.
- Causality: replay measures local next-action sensitivity, not task reward (sec 7, App. B.2).
- Transfer: a policy evolved on LHTB lowers DeepSWE scores for both models (Table 13), so policies are environment-specific.
- Harness comparisons depend on the model: with GPT-5.6-Luna, Codex is far ahead on DeepSWE and BrowseComp-Plus. The OpenClaw cross-harness gain (33 to 79 of 174) starts from a low base and uses a Qwen3.8-27B judge.

## 6. One experiment that would test the main claim
Repeat the LHTB skill-only and ContextEvo arms with several runs per task, report held-out-only scores with intervals, and add the token cost of the evolution loop next to the per-run savings.

## 7. What should be read next?
Self-harness (Zhang et al., 2026a), the trajectory-driven recipe the skill-only arm follows; Meta-harness (Lee et al., 2026); ACON (Kang et al., 2026) for evolved compression rules; Causal Agent Replay (Shah, 2026) for step-level replay; Long-Horizon-Terminal-Bench (Li et al., 2026d). On this wiki: [Context Language Models](/wiki/papers/2609.37725.md), where the model edits its own context instead.

## 8. Sharpest teaching angle for a 60 second video
On long terminal tasks, skills learned from an agent's own runs lowered its average score, while learning what the model should see raised it with fewer tokens. Show how it learns (rebuild what the model saw, name the failure, replay one step), then the caveat: one run per task, and held-out changes vary by setting.
