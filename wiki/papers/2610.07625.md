# Stateless Language Agents (SLA)

Topic: [agent context management](/wiki/topics/agent-context-management.md). Authors: Qizheng Zhang, Changxiu Ji, Isaac Sun and 15 others (Stanford, CMU, University of Washington, SambaNova Systems, UC Berkeley). arXiv 2610.07625v1, 6 Oct 2026.

## 1. Identity
"Stateless Language Agents: Scaling Long-Horizon Automated Research", arXiv 2610.07625, version v1 (the only version on 2026-10-14, and the one the video was made from).[^paper]

## 2. What problem does it address?
When research agents run for hundreds of millions of tokens, more tokens do not by themselves give more progress: agents replay growing histories, repeat each other's work, or stop experimenting while the token count keeps rising. The authors trace this to where research state lives and who decides what to try next.[^paper]

## 3. What is the method?
"Stateful search with stateless agents." No agent, the Advisor included, keeps its conversation across invocations. The harness owns the research state (candidate solutions and measured outcomes) and rebuilds a fresh context for each role at every invocation. Each epoch, a new Advisor session reads a harness-built evidence summary (best code and score, outcomes grouped by search direction, Worker status) and assigns a concrete experiment to each of several parallel Workers. Each Worker trial is a new session that sees only the task, its assignment, its retained candidate and local feedback. An independent, protected evaluator scores every candidate. Statelessness is enforced (new sessions, cleared saved sessions, Landlock filesystem isolation). Because the state lives in the harness, ablations can resume from identical checkpoints.[^paper]

## 4. What is the evidence?
All results are the authors' runs, against EvoX, CORAL and SwarmResearch with the same coding agents, models, seeds, task materials, protected evaluators and token counter.[^paper]
- Best full-budget result on every evaluated task (FrontierSWE four tasks at 700M, Anthropic kernel at 1B, SOL-ExecBench three tasks at 500M, Structured-LWE at 200M).
- Tokens to first match the strongest baseline's full-budget result, Anthropic kernel: 93.1% fewer with Codex (67.9M against 986.3M, mean curves of three runs, vs SwarmResearch) and 84.4% fewer with Claude Code (138.5M against 888.3M, one run per method, vs CORAL). The abstract's "over 84%" is the lower of the two. On other tasks the saving ranges from 9.6% (Git to Zig) to 95.9% (SOL #58); on SOL #1 EvoX reached the target sooner.
- Horizon reversal: on all four FrontierSWE tasks (Codex, one run each) SLA trails the strongest baseline at 25% of the budget and leads at 100%.
- Ablations from shared checkpoints (three runs each): removing Advisor context reconstruction, Worker isolation or Advisor assignments lowers mean progress in every comparison; every variant keeps the agents stateless.
- Coordination cost: the Advisor uses 0.24% and 0.51% of tokens in the two analyzed runs; its share of estimated model cost is higher, 1.20% and 2.29%.
- Trace example (D.3): without assignments, three Workers built the same feature from the same start and none improved the score; similar overlap in the other two runs. The authors say traces do not measure rates.

## 5. What does it not show?
- That statelessness itself is why SLA wins. "Our ablations change what each agent sees, not whether it keeps its conversation across invocations." EvoX also starts a fresh agent per generation and SLA still beats it, so the gain cannot be put on dropping the conversation alone.
- Replication: only the Anthropic kernel with Codex and the ablations have more than one run.
- Cost: comparisons are matched on tokens; the cost estimates leave out the compute to run and evaluate experiments. "84% fewer tokens" is not "84% cheaper".
- Scope: every task has an executable evaluator; vague or slow-to-evaluate goals are untested.
- The headline saving is task- and setup-specific (see the range above).

## 6. One experiment that would test the main claim
Run SLA with one change: let each Worker (or the Advisor) resume its own conversation across invocations, while the harness still builds the same context on top. Compare from the shared checkpoints with three or more runs, over full-length runs as well as 100M continuations, and report tokens and dollar cost. That isolates the "stateless" part from the "focused context" and "assignment" parts the existing ablations cover.

## 8. Sharpest teaching angle for a 60 second video
Open on the paper's central question: give research agents a billion tokens; does the work still improve? Show the CORAL trace (one baseline run): the last gain at 231M, then 98% of the final 1,500 sessions with no tool calls while tokens keep flowing. Name the two choices (where research state lives, who picks the next experiment), then the answer: the harness keeps the research state, every invocation gets a fresh context for its role, and a stateless Advisor hands each Worker a different experiment. Evidence with its scope: over 84% fewer tokens to match the strongest baseline on one kernel task (lower of two setups), the Advisor under 0.6% of tokens (not cost), and the four-task reversal between 25% and 100% of the budget. Caveat: executable evaluators only, statelessness never ablated, most setups one run.
